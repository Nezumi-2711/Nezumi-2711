## About

I'm a frontend developer based in Vietnam 🇻🇳. I build web interfaces with **React, Next.js and TypeScript**, and I rely on AI coding agents to generate and iterate on the code: I define the requirements, review the output and test the result.

- Frontend apps and dashboards with React, Next.js, Tailwind and TanStack Query
- Supporting backend pieces on Cloudflare Workers, built with AI assistance
- Interfaces for AI agents using CopilotKit and the AG-UI protocol
- An AI-assisted workflow built on Claude Code, Codex and Gemini

Currently exploring agent-to-UI protocols (AG-UI), LangGraph workflows, and AI-assisted development with Claude Code.
